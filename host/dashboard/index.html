          1. 1Your server

            –

            Point the host app at your own copy of the Legacy server: the folder with rust_server.exe. It checks the file's SHA-256 against the verified build. We never supply or change the game's own server files except the adapter in step 2.

          2. 2Browser ready

            –

            Adds our adapter so players who signed in on the website can join. Your own players keep joining as before.

            • 3Connect to the website

              –

              On Your servers, register this server (or press New enrolment code on it) and paste the code here. One code links the gateway and lets you manage the server from the website's console. It lasts 15 minutes and works once.

            • 4Public address

              –

              Browsers join through the gateway at the wss:// address you registered on the website. They need HTTPS with a real certificate.

              How browsers reach the gateway

            • 5Run

              –

              The host app starts your server only after you agree here. It runs under the app's own Windows account (no password, not an administrator), and the watchdog restarts it with the last good save if it freezes.

                        An update is a .tar file made with Publish-Kit.ps1 or tools/build-kit-update.mjs. Compare its SHA-256 with the .sha256 file made beside it before you install.
