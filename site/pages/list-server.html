How it works

  1. 01

    Register

    Sign in and add your server: its name, region and the address players' browsers connect to.

    Registering
  2. 02

    Connect

    Install the host app on your server machine. It runs the gateway that lets browser players in, and links the server to your account.

    The host app
  3. 03

    Send the listing

    Describe the server, add tags, your Discord and wipe days. The Rust Legacy team checks every new server, then it's listed.

    Listing rules
  4. 04

    Run it

    Logs, restarts and backups in the console. Players, anti-cheat, bans and reports in Server admin, with your own team.

    Managing it

Run it from the website

Live log

Every line from the game server, gateway and host app, filtered by part and searchable.

Start, stop, restart

Each part on its own or all at once. The watchdog restarts a frozen server with its last good save.

Backups

Keep a copy before a wipe and restore one with the server stopped.

Players and anti-cheat

Who is online, suspicion scores, flags with the evidence behind them, and screenshots.

Bans and reports

Kick, timed or permanent bans, player reports, and rules for who may join.

Your team

Give people the server admin or moderator role. Everything they do goes in the audit log.

What you need

  • An account on this website. It owns the server.
  • Your own copy of the Legacy server on a Windows PC or VPS. We never supply or run the game's server files.
  • An HTTPS address for the gateway (wss://), for example a subdomain pointed at your machine.
  • The host app, which is being tested with the first server owners now. Ask in our Discord to take part.
