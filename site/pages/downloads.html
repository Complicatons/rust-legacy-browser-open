Check your download

  1. Open PowerShell in the folder you downloaded to.
  2. Run Get-FileHash .\RustLegacyLoader-<version>.zip -Algorithm SHA256 (or the host installer's file name).
  3. The Hash must match the SHA-256 above, every character. If it doesn't, delete the file and tell us on Discord.

The numbers on this page come from release manifests signed with the project's release key. Only download from your-domain.example.
