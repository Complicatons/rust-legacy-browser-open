The website has two new parts: [leaderboards](/leaderboard) and a [forum](/forum).

## Leaderboards

There are seven boards: Most active, Hunters (all animals, or one species), PvP, Gatherers, Builders, Crafters and Travellers. Each board can show one server or all of them, and all time, today, the last 7 days or the last 30 days. Every name links to that player's page, which shows their hours, animals, PvP kills, deaths, resources gathered, pieces built, items crafted and kilometres travelled.

The numbers come from the game server, never from the player's browser. Our gateway, which sits between the browser and the original server, counts what the server tells players:

- **Kills:** an animal's death message names the player who killed it, and so does a player's.
- **Gathering:** the server sends the "10 x Wood" message you see when gathering.
- **Crafting:** a craft counts only if it runs to the end.
- **Building:** a piece counts only once the server has placed it.
- **Distance:** only moves our anti-cheat accepted count.

Central also caps how much each server can add per second, so a forged report can't fill a board.

If you'd rather not be listed, the account page has a **Hide me** switch. It removes your name and your page from every board. The [privacy policy](/privacy) explains what is counted.

## Forum

The forum has six categories: Announcements, General, Help, Servers, Suggestions and Bug reports. You can post once you have an account with a username. Staff can pin, lock and delete threads, delete posts, and stop an account from posting for a set time. Every staff action is logged.

## Still to come

The boards stay empty until the gateway change reaches the test server, which happens with the next update. Players on the original desktop game aren't counted yet. The pictures above use sample data, not real players.
