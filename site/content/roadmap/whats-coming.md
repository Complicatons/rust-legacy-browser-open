## Testing against a real Legacy server

The next big step. The original server runs inside a sealed virtual machine and the browser port joins it through the gateway, using the test kit that is already built. Waiting on: the virtual machine software and a Windows test copy on the owner's PC, and the owner's go-ahead for each phase that runs original code. Until this is done, playing with original servers is **unproven**.

## The first real server

Once the real-server tests pass, the first public server. The plan recorded so far is a PvP server first, then an EU server, with the community deciding things like wipes and group limits.

## Tuning anti-cheat with real players

The cheat checks have only seen our own test server. Their limits get tuned with real traffic before any automatic kicks are switched on.

## Website, phase 2

- **Classic map.** The Island's classic layer is waiting for the community map image and permission to use it.
- **Community place names** for the map.
- **Password reset and email verification** go live once a mail provider is chosen.

## Fidelity gaps still open

The port is not finished. Known gaps include approximations in the lighting, a few particle rules that live in the game engine itself, and everything that can only be compared with the original once the real server runs.
