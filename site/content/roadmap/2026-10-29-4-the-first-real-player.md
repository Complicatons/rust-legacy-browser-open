Everything up to tonight was proven against test machines and automated bots. Tonight the first real server went up, and the owner joined it from an ordinary browser tab — the whole chain working end to end, for real, for the first time: the website, the account, the server, the connection between them.

## What happened

- **EU 1 is live.** The original Legacy server, running on its own machine, reachable by anyone with an account.
- **The owner signed up and joined from a plain browser tab.** No install, no download — exactly how a real player would do it.
- **The server saw a real player.** Confirmed independently: the public server list went from 0 players to 1 the moment the owner joined.

## Two false starts on the way

The first two join attempts failed outright, with nothing reaching the server at all. Chasing that down turned up a real gap — the website's security policy didn't allow the game page to talk to a server on a different address — and it's fixed now. It turned out not to be what was actually stopping the owner's browser, which genuinely has no explanation yet, but the join now works cleanly and repeatably, and the fix was worth having regardless.

## What's next

A few more checks before this counts as proven for every player: rejoining keeps the same character, a browser and a desktop player share one account properly, and the server holds up with several players at once. One live bug already turned up in the owner's first real session — an odd sound when switching items — now under investigation.
