Earlier today our test bots kept being kicked by the original server's anti-cheat, because the test machine still ran a build where players could walk through rocks.

## The new build on the test machine

The current build went onto the test machine: about 100 MB of new files, including solid rocks and the faster loading from yesterday. Then four bots walked, gathered, chatted and reconnected on the original server for 22 minutes.

- No kicks, no position corrections from the server and no unexpected disconnects.
- A fresh player joined in 79 seconds instead of almost ten minutes.
- The starting-inventory check passes: the server's own Rock, two Bandages and a Torch arrive on the belt.

## What's next

The original server itself froze twice today while saving the world. That still needs a cause before longer test runs.
