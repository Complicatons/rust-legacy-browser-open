The host app now has the pages owners need day to day.

## Players

Everyone in the game, in the browser and on the desktop, with their cheat score. From each row the owner can:

- send a private message;
- go to the player;
- bring the player to them;
- kick;
- ban for an hour, a day, a week, a month or for good;
- ask for a screenshot.

Bans can be lifted from the same page. The in-game actions show whether the server carried them out.

## Anti-cheat

Recent flags across all players, each named in plain words, such as "Teleport" or "Firing too fast". Selecting one shows that player's full evidence:

- the measurements behind every flag;
- the path they took, drawn from above, which makes a teleport or a straight climb easy to see;
- any screenshots.

Player reports can be resolved or dismissed from the same page.

The app uses the same rules as the website's admin page: the owner acts, and every action goes in the audit log, marked as coming from the host app.

## Backups

The freeze watchdog already kept the last good world saves. Now the owner can see them, keep a copy by hand (for example before a wipe vote) and put any copy back while the server is stopped. The save it replaces is set aside, not deleted.

## What's next

Updates for the gateway and the browser files, then an installer.
