Accounts made with Steam or Discord have no password to type into a desktop launcher. Instead, the launcher shows a short code. The player signs in on the website, opens **Sign in a launcher** and types it.

- **Typed, never clicked:** the code has to be typed. A link carrying a code is ignored, so nobody can trick a player into signing someone else's launcher in as them.
- **Your launchers, listed:** the account page now shows each signed-in launcher, whether it is connected or in game, and when it last checked in, with a **Sign out** button for each.

The launcher window itself is still to come.
