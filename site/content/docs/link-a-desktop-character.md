title: Link your desktop character
summary: Play the same character from the desktop game and the browser
group: Playing online

---

If you already play a server with the original desktop game, you can link that character to your website account. Then you play the same character from your browser, and your reports carry your account.

1. In the desktop game, on that server, type `/browserlink` in chat. The game shows a short code.
2. On this website, open the server on [Servers](/servers) and press **Link desktop character**.
3. Type the code within a few minutes.

One character per account per server. If you link the wrong one, the server owner can unlink it from their host app.
