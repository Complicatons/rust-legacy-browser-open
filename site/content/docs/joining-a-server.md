You play on community servers, each run by its own owner. All you need is an account on this website and a desktop browser with a keyboard and mouse.

## Join

1. [Create an account](/register), or sign in with Steam or Discord.
2. Open [Servers](/servers). Online servers show their players and slots. Search by name or by tag (for example *vanilla* or *weekly wipe*), and filter by region.
3. Pick a server to see its description, its wipe days and its Discord, then press **Join server**.

The game loads in the same tab. Your character on that server belongs to your account, so you come back to it from any computer.

Prefer the original desktop game? Use [the game loader](/docs/the-game-loader) on servers that run our server software. It's the same account and the same character.

## When a server says no

Some servers only let in accounts that meet their rules. The server's page shows them under **To join**:

| Rule | What to do |
| --- | --- |
| Account N days+ | Your account is too new for this server. Try again later, or pick another server. |
| Steam linked | Link Steam on your [account page](/account). |
| Verified phone | Add and verify a phone number on your account page. |
| Steam level, VAC or game bans | The server checks your Steam profile. Make your profile and game details public on Steam. |

If you are banned from a server, joining it tells you so. Ask that server's owner on their Discord: only they, or the Rust Legacy team, can lift it.
