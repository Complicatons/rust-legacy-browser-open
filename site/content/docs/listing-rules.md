The server list is for servers players can trust. By sending a listing you agree that your server:

1. **Describes itself honestly**: its rules, wipe schedule, mods and anything that changes the game.
2. **Sells no gameplay advantage.** Cosmetics and supporter roles are fine; paid kits, items or priority over other players are not.
3. **Has a team that doesn't cheat** or abuse admin powers against players.
4. **Takes reports seriously** and uses bans for cheating and abuse, not to settle grudges.
5. **Runs its own legitimate copy** of the Legacy server.
6. **Keeps its name and description clean**: no hate, no adult content, no impersonating another server or the Rust Legacy team.

The Rust Legacy team checks every new listing before it shows. A listing that breaks these rules is rejected with a note saying why. A server that breaks them later can be unlisted or suspended. A suspended server leaves the list and its gateway stops working until it's restored.

Questions? Ask in our [Discord](https://discord.gg/your-invite).
