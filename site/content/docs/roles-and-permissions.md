Each server has its own team. The Rust Legacy team (site staff) sits above every server.

| Role | Where | Given by |
| --- | --- | --- |
| **Site staff** | Every server and the whole website | The Rust Legacy team |
| **Server owner** | Their server | Registering the server |
| **Server admin** | One server | The server owner |
| **Moderator** | One server | The server owner or a server admin |

## What each can do

| | Moderator | Server admin | Server owner | Site staff |
| --- | --- | --- | --- | --- |
| See players, flags, evidence, reports | Yes | Yes | Yes | Yes |
| Kick, message, teleport to | Yes | Yes | Yes | Yes |
| Ban | Up to 24 hours | Any length | Any length | Any length, and network bans |
| Bring a player, ban desktop players | No | Yes | Yes | Yes |
| Change the join policy, see the audit log | No | Yes | Yes | Yes |
| Give moderator roles | No | Yes | Yes | Yes |
| Give server admin roles | No | No | Yes | Yes |
| Console: logs, restarts, backups | No | No | Yes | Yes |
| Listing, host app key, enrolment | No | No | Yes | No |
| Approve listings, suspend servers | No | No | No | Yes |

Nobody can act on themselves or on someone with an equal or higher role on that server.

## Giving someone a role

In Server admin, under **Server team**, enter their account id (they find it on the Server admin page) and pick the role.
