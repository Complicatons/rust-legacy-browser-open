## The original server

- **The original 2014 Rust Legacy server ran for the first time**, on a locked-down test machine in the cloud. It made 0 network connections outside its test.
- **A player in a web browser joined it** and spawned on the island. That took 3 protocol fixes and 0 changes to the server's game rules.
- The admin tools were checked end to end, from the website to the game and back. That caught 2 bugs before any real server ran.

## In the game

- **Rocks and cliffs are solid**: all 8,344 of them block players, bullets and building. In 889 test walks into rocks, nobody went through, and standing on one no longer freezes the game.
- **You move like the original**: you slide along rocks and walls, and nothing pushes you through them.
- **The original building preview**: see-through, pulsing green or red, with the bouncing arrow on deployables.
- **Grenades, supply signals and flares bounce and roll** with the original weights.
- **Melee swings hit the ground**, with the original impacts and sounds.
- **Inventory sounds** are back: clicks and the craft sound.
- **Ctrl+W no longer closes the game.** Crouch is Ctrl, so crouch-walking used to close the browser tab. The game now plays fullscreen and keeps the keyboard.
- **Tested in Firefox and Chrome** as well as Edge.

## Faster loading

- **The download is 210 → 167 MB**, from lighter animations and smaller files. Not one pixel changed.
- **Your first join takes 25 s instead of 83 s.** Later visits take about 7 s instead of 65 s.
