These are the original game's default keys. Each action can have two keys, and you can change them all.

## Moving

| Key | Action |
|---|---|
| **W A S D** | Walk forward, left, back, right |
| **Space** | Jump |
| **Left Ctrl** | Crouch (hold) |
| **Left Shift** | Sprint (hold) |

See [Moving around](/wiki/guides/moving-around) for how fast each one is.

## Using things

| Key | Action |
|---|---|
| **Left mouse** | Fire, swing or place |
| **Right mouse** | Aim down the sights |
| **R** | Reload |
| **1** to **6** | Pick the item in that belt slot |
| **E** or **middle mouse** | Use what you're looking at. Hold it on a door, fire or box for its menu |
| **Tab** | Inventory and crafting |
| **F** | Flashlight on a gun |
| **G** | Laser sight on a gun |

## Talking

| Key | Action |
|---|---|
| **Enter** or **T** | Chat |
| **V** | Voice chat (hold) |
| **F1** | Console |

More in [Chat, voice and the console](/wiki/guides/chat-voice-console).

## Changing your keys

![The key list in Options](/site/generated/media/guides/options-keys.jpg)

Open **Options** from the main menu. Under *input* there's a row for each action with two boxes:

1. Click a box. It shows **...** while it waits.
2. Press the key or mouse button you want. **Escape** empties the box instead.
3. Click **Apply Changes**. Nothing changes until you do.

*Default Keys: Restore* puts every key back. The game doesn't warn you if one key is used twice: both actions happen when you press it. The mouse wheel can't be bound, and the belt keys (1–6) and **E** can't be changed. The *Use* row is there, but the original game never reads it.

You can do the same from the console: `input.bind Up W UpArrow` sets both keys for *Up*, and `input.keys` lists them all.

## Browser extras

Playing in a browser adds a few keys of our own:

- **Escape** frees the mouse and opens the menu.
- **F2** frees the mouse without opening anything. You can change it to F3 or F4 in Options.
- **Alt+Enter** toggles fullscreen.
