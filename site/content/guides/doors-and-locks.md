There's no separate lock to craft: **every door and gate has a 4-digit code lock built in**.

![The hut's door](/site/generated/media/guides/door.jpg)

| Door | Recipe | Health | Explosive charges |
|---|---|---|---|
| [[item:Wooden Door]] | 30 wood | 500 | 1 |
| [[item:Metal Door]] | 200 metal fragments (workbench) | 1,000 | 2 |
| [[item:Wood Gate]] | 120 wood | 1,800 | 3 |
| [[item:Wood Gateway]] | 400 wood | 2,000 | 5 |

Doors go in a doorway; gates go in a wood gateway.

## Setting the code

When you place a door you're its **owner**, and you can always open it. Hold **E** on it for the menu:

![The door menu](/site/generated/media/guides/door-menu.jpg)

- **Change Lock** (owner): set a new 4-digit code. This also takes access away from everyone who had it.
- **Lock / Unlock** (owner): an unlocked door opens for anyone.
- **Enter Code** (everyone else): the right code gives you access to that door for good. You'll see *"You can now access this door!"*

A brand-new door has no code yet, so nobody but you can open it until you set one. A wrong code makes you wait 5 seconds before the next try (*"Too fast! Try again later."*), so guessing all 10,000 codes takes a very long time.

## How strong is a door?

Lockpicks don't work on doors or gates: the [[item:Handmade Lockpick]] only opens a locked death sack (see [Death and respawning](/wiki/guides/death-and-respawning)).

Guns can't damage doors at all. Melee barely can: a wooden door takes only 10% of melee damage, so chopping through it with a hatchet takes around 200 hits. A metal door ignores melee completely. Explosives are the real threat, see [Raiding](/wiki/guides/raiding).
